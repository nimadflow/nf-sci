# CAPSULE V1 Reproduction Executor Role Statement

REPRODUCTION_EXECUTOR is limited to read-only capsule execution and typed reporting.

Allowed: verify the tar SHA, extract into a safe new directory, verify the manifest, run the capsule runner, and return the receipt.

Forbidden: live mutation, truth promotion, RED authority, SSOT access, SSH to the sibling machine, cross-WSL source copying, and changes to body, runtime, registry, frontier, or services.

Not tested: body, dialogue, autonomous loops, trading, genotype identity, or reproduction of the complete NF-SCI system.

A first-attempt divergence is a valid typed result and must not be concealed.
